### 🚕 Cab Company Management System

A Java vehicle-hire system for a taxi and bus company, built to apply object-oriented programming, data structures, and file handling to a practical problem.

**Tech Stack:**

![Java](https://img.shields.io/badge/Java-ED8B00?style=flat-square&logo=openjdk&logoColor=white)
![OOP](https://img.shields.io/badge/OOP-Inheritance-blue?style=flat-square)
![Data Structures](https://img.shields.io/badge/Data%20Structures-HashMap-lightblue?style=flat-square)

**Key Features:** Abstract `Vehicle` superclass with `Cab` and `Bus` polymorphism · O(1) vehicle lookup using a `HashMap` · Circular route logic for wrap-around journeys · CSV parsing · Automated reporting
